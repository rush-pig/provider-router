Linux · systemd

上面的开关使用桌面登录自启动。若希望服务器在开机后立刻运行、无需登录，可安装用户级 systemd 服务： 

bash scripts/install-user-service.sh
sudo loginctl enable-linger "$USER"

安装脚本会生成 ~/.config/systemd/user/provider-router.service，并启用当前用户服务。

路由规则

provider/model：第一个 / 之前是提供商，之后完整保留给上游，因此 openrouter/anthropic/claude-sonnet-4.5 会路由到提供商 openrouter，上游模型为 anthropic/claude-sonnet-4.5。

请求方法、路径、查询串、请求头（逐跳头除外）和其余 JSON 字段都会保留；仅替换鉴权头与模型字段，并重新计算内容长度。

GET /models 或 /v1/models 会并发读取各提供商模型并汇总；单个提供商失败时保留其本地模型列表并报告错误。
